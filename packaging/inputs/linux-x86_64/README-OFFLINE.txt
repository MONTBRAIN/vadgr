Vadgr 0.5.0

Vadgr runs tasks on your computer using the model provider and tools you
connect. The package includes its computer-control payload and Python runtime.
You do not need a source checkout or a separate Python installation to use it.

On Windows, macOS and native Linux, open Vadgr to manage the installed machine.
Use Machine for settings and paired devices, Providers for provider
connections, and Settings for updates, repair and uninstall. WSL uses the CLI.
The command "vadgr --help" lists commands. "vadgr status" reports daemon
status. "vadgr start" and "vadgr stop" start and stop the daemon.

Local settings, offline repair and uninstall do not require a source-code
repository. Tasks that use a remote model provider or connected service need
that service. An update check or download needs the selected update source.

The package includes these offline documents:

- legal/TERMS.txt: the packaged distribution terms and version
- legal/LICENSE.txt: Apache License 2.0
- legal/NOTICE.txt: Vadgr's copyright and attribution notice
- legal/PRIVACY-NOTICE.txt: local information and network data destinations
- legal/SECURITY-AND-PERMISSIONS.txt: computer access and security controls
- legal/SUPPORT.txt: publisher and support contacts
- legal/UNINSTALL-AND-DATA.txt: preserved data and explicit deletion
- legal/THIRD-PARTY-NOTICES.txt: notices for included components
- legal/LICENSES/: the included components' license texts
- sbom/vadgr-0.5.0.spdx.json: the software-component inventory

Source offers are included when a component's license requires them. The
installed Legal and notices control opens the local documents. Keep copies
before uninstalling if you want to retain the package-owned documents.

Terms acceptance records the accepted version and hash. A changed terms
version requires new acceptance. The packaged distribution terms do not
replace or reduce the rights granted by the included open-source licenses.
